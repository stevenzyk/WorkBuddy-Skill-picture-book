# 绘本质量与一致性核验清单

本清单将质量控制分为**「代码自动硬拦截（管文本与引用）」+「样张人工确认（管审美与像不像）」+「分批事实审图（管画面穿帮）」**三道关口，确保在强弱模型下都能稳定交付。

---

## 关口 1：生图前脚本编译拦截（必跑，零人工遗漏）

写完 `story_plan.json` 后，先运行编译器：

```bash
python <SKILL_DIR>/scripts/compile_prompts.py --plan ./book/story_plan.json
```

确认终端输出 `✅ 编译通过`（无任何报错）：
- [ ] 所有角色已填数字 `age` 与 `gender`，成年角色描述与动作中无 `son / daughter / boy / girl` 等辈分幼童偏置词。
- [ ] 每套 `Look` 均覆盖全部角色的全身穿戴（含鞋履/赤脚状态），跨季/入水/变装页已切换对应 `look_id`。
- [ ] 每页 `present_characters` 中的每个角色都在 `character_actions` 中有独立位置、动作与视线描述（无漏人）。
- [ ] 每页中文文案的核心具体名词均已列入 `caption_nouns_en` 且 100% 出现在编译后的英文 Prompt 中。

---

## 关口 2：阶段 3A「造型基准图 + 2 页样张」用户确认

生成完全部 `ref_*.png` 基准图 + `page_01_cover.png` + `page_02.png` 后，先自己用 `ViewImage` 检查并展示给用户确认：
- [ ] **站姿全身基准图**：所有角色是否平地并排自然站立、头到脚完整入镜？长相、发型、年龄感与相对身高差是否准确？
- [ ] **多造型一致性（如有 ≥2 套 Look）**：第 2 套造型（如冬装/赤脚装）是否保住了与第 1 套完全相同的脸部与身高比例，且衣服已彻底切换？
- [ ] **封面与首张样张**：封面顶部是否留足标题空白且不挡脸？正文样张是否自然互动（无全员直视镜头的棚拍贴图感）？

---

## 关口 3：阶段 3B 批量生图「5 题事实反问审图」（每 2–3 页必答）

严格照 `prompts_manifest.md` 原样复制 Prompt 与 `reference_images`（**禁止手改或缩写**），每生成 2–3 页立即用 `ViewImage` 逐页回答以下 5 个事实问题，任一异常**当场重生成**：

1. **人数与身高**：图中实际有几人？每个人的身高比例是否与站姿基准图一致（有无成年人缩水成儿童、漏人或岸边配角乱入载体）？
2. **视线与姿态**：人物眼睛在看哪里？（正文页有无僵硬直视镜头、机械复刻坐姿的「棚拍贴图感」？）
3. **文案核心物体**：本页 `caption_nouns_en` 列出的物体（如野餐食物、树荫、贝壳）是否在画面中清晰可见？
4. **造型与衣鞋**：人物穿的是不是本页 `look_id` 指定的衣服和鞋履状态（如冬装页是否真穿了冬装、赤脚页是否全员无鞋）？
5. **比例、肢体与状态**：道具相对人体的尺寸是否合理（无巨型相机）？每人是否恰好两手两脚？分阶段状态（如包扎前/后）是否准确且未串味到健康同类角色？

---

## 关口 4：排版前硬校验与一键构建

运行内置构建器校验并生成双格式成品（**严禁另写 HTML/PDF 脚本**）：

```bash
python <SKILL_DIR>/scripts/build_book.py --book ./book/book.json --check-only
python <SKILL_DIR>/scripts/build_book.py --book ./book/book.json --out-dir ./book --dpi 150 --crop-watermark
```

- [ ] `total_pages` 与实际面数（封面 1 + 正文 N + 封底 1）完全一致，磁盘图片无缺失、无页码错位。
- [ ] 封面标题位于顶部留白区不遮挡面部，最后一页结局画面与文案完美呼应。
