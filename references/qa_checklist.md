# 绘本质量与一致性核验清单

本清单通过**「编译前文学与代码硬拦截」+「样张人工确认」+「分批 5 题事实审图」+「排版硬校验」**四道关口，同时守住**绘本文学感染力**与**跨页视觉零穿帮**。

---

## 关口 1：文学润色自检 + `compile_prompts.py` 硬拦截（生图前必跑）

1. **绘本文学性自检（拒绝看图说话流水账）**：
   - [ ] 全书是否有一条明确的 `story_thread`（串珠线索）且首尾呼应，而非干瘪的行程流水账？
   - [ ] 每页 `text_zh` 是否符合用户选定的文风（童趣韵律 / 好奇寻宝 / 温暖收集）？
   - [ ] 是否已删掉“红白格子/藤编/奶油白”等生图说明书修饰词，并融入了**声音/拟声词、短对话、触觉温度或小比喻**（无连续两页 `XX 做了 YY` 汇报句）？
   - [ ] 每页 `text_zh` 是否严格锚定在本页 `event_core` 同一瞬间事件上（无异时空脱节抒情）？
2. **运行编译器硬校验（必须 `exit 0` 零报错通过）**：
   ```bash
   python <SKILL_DIR>/scripts/compile_prompts.py --plan ./book/story_plan.json
   ```
   - [ ] 成年角色无 `son/daughter/boy/girl` 等幼童化偏置词，且中文台词对成年儿女避免生硬旁白点名“儿子/女儿”（改用昵称或“我们/姐姐/弟弟”）。
   - [ ] 同一地点跨时段场景已设相同 `location_group` 并复用一致的窗框/窗帘/沙发/树木锚点词；室内场景无户外道具升空违和状态；居家上床页已用 `outfit_overrides_en` 脱去外鞋。
   - [ ] 全书多人页已设计交替错落队形（围坐/半圆/前后景/行走），未照抄基准图的从左到右一字排开；全书 `(day, time_of_day)` 单向推进无倒流。

## 关口 2：阶段 3A「站姿基准图 + 封面与首张样张」用户确认

生成完全部 `ref_*.png` + `page_01_cover.png` + `page_02.png` 后，先自己审图再交给用户确认：
- [ ] **站姿全身基准图**：所有角色平地并排自然站立、头到脚完整入镜且鞋子下方留有约 15% 地板留白；长相、发型与相对身高差准确。
- [ ] **封面与首张样张零穿帮**：顶部标题留空 28% 不挡脸，全员鞋子与前景道具完整无切边；首张样张符合室内外物理常识（如室内绝无悬空飞行的风筝），且人物呈自然互动站位而非呆板罚站。

## 关口 3：阶段 3B 批量生图「6 题事实反问审图」（每 2–3 页必答）

严格按 `prompts_manifest.md` 标注的**画幅比例**、**Prompt** 与**必传参考图**调用 `ImageGen`（禁止手改缩写），每生成 2–3 页立即用 `ViewImage` 逐页回答以下 6 题，任一异常**当场重生成**：

1. **人数与身高**：图中实际几人？身高比例是否与站姿基准图一致（无成年人缩水、无漏人或配角乱入）？
2. **队形变化与脚底留白**：是否打破了与上一页雷同的“从左到右一字排开罚站”？全员鞋底与前景杯盘下方是否留有清晰地面边距（无切脚尖/切杯底）？
3. **空间装修连贯与室内外物理常识**：同一房间/公园的窗框、窗帘、沙发或树林是否与前页一致（无中途换装修）？道具状态是否符合室内外常识（如风筝在室内绝不可飞在半空；文字写“灯暗啦”则台灯不可刺眼大亮）？
4. **图文对齐与倒水/连线闭合**：`event_core` 与 `caption_nouns_en` 物体是否准确？若有倒水/倒果汁，水柱是否仅从壶嘴准确流入杯口（无悬空漏水或手指凭空流水）？风筝线/牵引绳是否连续无半空断裂？
5. **衣鞋与居家/涉水状态**：穿戴是否匹配当前 `look_id` 与 `outfit_overrides_en`（踩浪页是否真正光脚、回家上床睡觉页是否已脱去户外运动鞋/皮鞋）？
6. **道具比例与肢体**：随身道具相对人体比例是否正常（无角落巨型相机）？每人是否恰好两手两脚？

## 关口 4：排版前硬校验与一键构建

运行内置构建器输出 HTML 与打印级 PDF（**严禁另写 HTML/PDF 脚本**）：

```bash
python <SKILL_DIR>/scripts/build_book.py --book ./book/book.json --check-only
python <SKILL_DIR>/scripts/build_book.py --book ./book/book.json --out-dir ./book --dpi 150 --crop-watermark
```
