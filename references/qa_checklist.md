# 绘本质量与一致性核验清单

一致性依靠**「边生成边用事实反问审图 + 排版前硬校验」**的闭环，而不是抽象地看一眼就说“没问题”。

---

## 阶段 A：边生成边审图（每生成 1–3 页，必须逐条回答 5 个事实问题）

用 `ViewImage` 打开刚生成的图片，**必须用事实作答以下 5 题**；任意一题答出异常，**当场重生成该页**：

1. **人数与身高**：画面里实际有几个人？每个人的身高比例是否与设定年龄一致（成人角色有没有缩水成儿童？相似角色有没有撞脸？）
2. **视线与姿态**：人物的眼睛都在看哪里？（正文页有没有全员僵硬直视镜头、机械复刻基准图坐姿的「棚拍贴图感」？）
3. **文案核心物体**：本页中文文案提到的核心物体/环境（如「午饭/食物」「树荫」「贝壳」「小树」），在图里是否肉眼清晰可见、没有漏画或被偷换？
4. **衣鞋与季节常识**：服装、恒穿装备和鞋履是否与当前天气/场景自洽？（有没有雪地穿短袖、踩浪穿运动鞋、无故换衣？）
5. **道具比例与肢体**：核心道具大小是否合理（如相机有没有大得像人头）？每人是否恰好两手两脚？带翅膀配角有无把翅膀长到人身上？分阶段状态（如包扎前/后）是否准确且未串味？

---

## 阶段 B：排版前硬校验（严禁跳过）

1. **运行技能内置校验脚本（禁止另写校验脚本）**：
   ```bash
   python <SKILL_DIR>/scripts/build_book.py --book ./book/book.json --check-only
   ```
   确认：
   - [ ] `total_pages` 与用户确认的面数完全一致（封面 1 + 正文 N + 封底 1）。
   - [ ] `book.json` 引用的每一张图片文件在磁盘上真实存在、可正常读取，且无 `ref_*.png` 混入。
2. **页码 ↔ 内容逐页核对（最高优先级）**：
   - [ ] 逐页核对 `page_01_cover.png`、`page_02.png` …… 的实际画面内容是否与该页文案一一对应，杜绝文件名顺移/错位。
   - [ ] 重点核验**封面**（人物在中下部，顶部有留白给标题，不挡脸）与**最后一页结局**（图文一致、不脱节）。

## 阶段 C：全书一致性总检表

| 检查维度 | 核验要点 | 发现问题如何修复 |
|---|---|---|
| **人物与身高** | 任意两页的主角外貌、相对身高（尤其成人子女 vs 父母）、画风是否统一？ | 改用站姿全员基准图 + 写死 `full-grown adult, as tall as ...` + 去掉 `children's book` 偏置词 |
| **姿态与互动** | 坐姿/站姿是否自然多样？正文页人物是否与剧情元素互动而非全员看镜头摆拍？ | 补充具体视线方向（`looking at ...`）与 `candid natural moment, NOT looking at the camera` |
| **文案名词映射** | 文案中每个具体名词（午饭/树荫/西瓜等）是否在图中如实出现？ | 对照脚本「文案核心名词清单」补全英文 Prompt 后重生成 |
| **衣鞋与常识** | 单日故事是否服装一致？跨季节故事是否按季节换装？踩浪是否全员光脚？ | 补全分季服装锚点或显式写 `all barefoot` / `wearing winter coats and boots` |
| **载体与道具** | 船/车/相机/灯笼的结构、部件数、相对人体尺寸比例、持有状态是否一致？ | 传入道具基准图 + 相对人体部位锁死尺寸（如 `palm-sized`）与 `holding / resting` |
| **动物 / 固定物** | 动物风格类型与体型比例（动静一致）是否稳定？核心固定物是否逐页交代且暗光保色？ | 传入对应基准图 + 锁定三重体型/保色声明或显式 `not visible` |
| **场景与光照** | 同场景相邻页背景细节与光线是否按段统一？有无照片实景背景？ | 逐字复用内嵌光词的场景锚点；纯风景页去掉人物参考图 |
| **交付与水印** | HTML 具备单页/对开/滚动翻页？PDF 含完整图文且尺寸一致？是否需去右下角水印？ | 使用 `scripts/build_book.py` 一键输出，需去水印加 `--crop-watermark` |
