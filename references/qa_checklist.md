# 绘本质量与一致性核验清单

本清单通过**「编译前文学与代码硬拦截」+「样张人工确认」+「分批 5 题事实审图」+「排版硬校验」**四道关口，同时守住**绘本文学感染力**与**跨页视觉零穿帮**。

---

## 关口 1：文学润色自检 + `compile_prompts.py` 硬拦截（生图前必跑）

1. **绘本文学性自检（拒绝看图说话流水账）**：
   - [ ] 全书是否有一条明确的 `story_thread`（串珠线索）且首尾呼应，而非干瘪的行程流水账？
   - [ ] 每页 `text_zh` 是否符合用户选定的文风（童趣韵律 / 好奇寻宝 / 温暖收集）？
   - [ ] 是否已删掉“红白格子/藤编/奶油白”等生图说明书修饰词，并融入了**声音/拟声词、短对话、触觉温度或小比喻**（无连续两页 `XX 做了 YY` 汇报句）？
   - [ ] 每页 `text_zh` 是否严格锚定在本页 `event_core` 同一瞬间事件上（无异时空脱节抒情）？
2. **运行编译器硬校验（必须 `exit 0` 零报错通过）**：
   ```bash
   python <SKILL_DIR>/scripts/compile_prompts.py --plan ./book/story_plan.json
   ```
   - [ ] 成年角色无 `son/daughter/boy/girl` 等幼童化偏置词；在场角色无漏写动作；`caption_nouns_en` 100% 进图。
   - [ ] 所有在场道具均已填 `prop_states_en` 挂载/放置位置；涉水/脱鞋单页已填 `outfit_overrides_en`（含 `barefoot` 自动剥离鞋袜）。
   - [ ] 全书 `(day, time_of_day)` 单向推进，无“晚霞 → 白天 → 落日”时间倒流。

---

## 关口 2：阶段 3A「站姿基准图 + 封面与首张样张」用户确认

生成完全部 `ref_*.png` + `page_01_cover.png` + `page_02.png` 后，先自己审图再交给用户确认：
- [ ] **站姿全身基准图**：所有角色平地并排自然站立、头到脚完整入镜且脚底有留白；长相、发型与相对身高差准确。
- [ ] **封面与正文画幅匹配**：封面按封面画幅生成（顶部留空 28% 不挡脸，角落无孤立巨型道具）；正文按正文插画框画幅生成（如方形绘本正文用 `4:3` 横画幅），人物自然互动不僵硬。

---

## 关口 3：阶段 3B 批量生图「5 题事实反问审图」（每 2–3 页必答）

严格按 `prompts_manifest.md` 标注的**画幅比例**、**Prompt** 与**必传参考图**调用 `ImageGen`（禁止手改缩写），每生成 2–3 页立即用 `ViewImage` 逐页回答以下 5 题，任一异常**当场重生成**：

1. **人数与身高**：图中实际几人？身高比例是否与站姿基准图一致（无成年人缩水、无漏人或配角乱入载体）？
2. **视线与构图边距**：人物视线是否在与剧情互动（无直视镜头棚拍感）？头顶与脚尖/前景道具是否完整留有边距（未被底边切脚）？
3. **图文核心元素**：本页 `event_core` 与 `caption_nouns_en` 对应的物体/动作是否清晰准确（多人杯盘数量是否合理）？
4. **衣鞋与局部覆盖**：人物穿戴是否匹配当前 `look_id` 与 `outfit_overrides_en`（如踩浪页是否真正全员光脚无运动鞋、跨季页是否已换冬装）？
5. **道具比例与肢体**：随身道具相对人体比例是否正常（无角落巨型相机）？每人是否恰好两手两脚？

---

## 关口 4：排版前硬校验与一键构建

运行内置构建器输出 HTML 与打印级 PDF（**严禁另写 HTML/PDF 脚本**）：

```bash
python <SKILL_DIR>/scripts/build_book.py --book ./book/book.json --check-only
python <SKILL_DIR>/scripts/build_book.py --book ./book/book.json --out-dir ./book --dpi 150 --crop-watermark
```
