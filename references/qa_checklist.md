# 绘本质量与一致性核验清单

一致性依靠**「边生成边核验 + 排版前硬校验」的流程闭环**，而不是等全部图片生成完毕后再统一返工。

---

## 阶段 A：边生成边核验（每生成 1–3 页立即执行）

每生成 1 页（尤其是多人同框页、核心动作页、场景切换页），立即用 `ViewImage` 检查以下 5 项，发现问题**当场重生成**：

- [ ] **图文对应**：画面核心动作是否精确还原文案？（无「文字写一起做、画面各做各的」「文字写伸手捞、画面端坐不动」）
- [ ] **人数准确（多人页）**：数清共享载体上的人数是否恰好等于角色总数，有无漏人或把岸边配角画上载体？
- [ ] **角色辨识**：主角与全员基准图的长相、发型、身高差、服装、恒穿装备是否一致？相似角色有无撞脸？
- [ ] **肢体与附肢**：每人是否恰好两只手两条腿？带翅膀配角的翅膀是否长在自己身上？飞行页有无多出披风/飘带？
- [ ] **核心元素**：核心载体、动物配角、固定物体、贯穿道具是否与各自基准图一致？状态阶段（如包扎前/后）是否准确且未串味到同类角色？

---

## 阶段 B：排版前硬校验（先做页码与文件核对，再查画面）

1. **运行自动化校验脚本（必做）**：
   ```bash
   python scripts/build_book.py --book book.json --out-dir ./output --check-only
   ```
   确认：
   - [ ] `total_pages` 与用户确认的面数完全一致（封面 1 + 正文 N + 封底 1）。
   - [ ] `book.json` 引用的每一张图片文件在磁盘上都真实存在、可正常读取。
   - [ ] 无 `ref_*.png` 或无关参考图混入正页列表。
2. **页码 ↔ 内容逐页核对（最高优先级）**：
   - [ ] 逐页核对 `page_01_cover.png`、`page_02.png` …… 的实际画面内容是否与该页文案一一对应，杜绝文件名顺移/错位。
   - [ ] 特别核验**封面**（标题位于顶部留白区、不遮挡人物脸部与身体）与**最后一页结局**（最易图文脱节）。

---

## 阶段 C：全书一致性总检表

| 检查维度 | 核验要点 | 发现问题如何修复 |
|---|---|---|
| **人物与多角色** | 任意两页的主角外貌、服装、身高差、画风是否统一？恒穿装备是否每页都在？ | 确认传入主角/全员基准图 + 区分性锚点 + 逐个点名位置动作后重生成 |
| **载体与道具** | 船/车/灯笼等结构、部件数、颜色、尺寸是否统一？固定数量道具是否恒等于 `N`？持有状态是否连贯？ | 传入道具基准图 + 补全四维外观锚点与 `holding / no ... in hand` |
| **动物 / 幻想配角** | 造型风格、相对人物比例（静态 vs 动态）、角/耳/尾、发光状态是否统一？ | 传入配角基准图 + 锁定风格类型与三重体型描述 |
| **核心固定物体** | 唯一性、位置、大小、颜色（含夜晚/黄昏保色）是否统一？不在场页是否显式 `not visible`？ | 传入固定物基准图 + 重申 `one single` 与保色声明 |
| **场景与光照** | 同一场景相邻页背景细节（围栏/树/礁石）与天空光线是否按段统一？有无照片实景背景？ | 逐字复用内嵌光词的场景锚点；纯风景页去掉人物照片参考，`input_fidelity` 设 `low` |
| **动作与方向** | 飞/跑/挥手姿态是否到位？上下山/进出洞方向是否正确？标志性动作是否落在唯一归属页？绕圈有无断裂？ | 补充姿态化动词、方向朝向与完整可见声明后重生成 |
| **状态连续性** | 递进状态是否按前页铺垫逐页推进、无提前剧透、无跨同类角色串味？ | 核对基准图是否为初始态；显式绑定「状态 + 所属角色」与健康角色隔离声明 |
| **相邻页构图** | 有无相邻两页姿势/构图高度重复？ | 调整脚本换独立动作或景别后重生成 |
| **交付规格** | HTML `@page` 尺寸、PDF 毫米尺寸与页数是否与用户确认规格完全一致？ | 通过 `scripts/build_book.py --book book.json` 统一生成确保同步 |
