# 跨页一致性与防漂移规范

本文件汇总童话绘本创作中保证**人物本体、造型切换（Look）、随身道具、动物配角、时间线与构图留白**跨页一致的通用规则。核心约束已通过 `scripts/compile_prompts.py` 在代码层强制落地。

---

## 一、底层架构：「角色本体（Identity） + 造型状态（Look） + 页级微调」

1. **客观身份标签合成（防辈分词幼童化偏置）**
   - 读照片后先与用户确认每个角色的**真实数字年龄、性别、相对身高关系**。
   - 编译器自动根据 `(age, gender)` 合成客观视觉主语（如 `the 24-year-old adult man`），并用 `{c1}`、`{c2}` 占位符展开。
   - **严禁**对成年角色使用 `son / daughter / boy / girl / kid / child` 等家庭辈分或幼童词，从源头杜绝生图模型触发“父母带小孩”先验导致成人身高缩水。
2. **平地站姿全身基准图（锁死头身比与相对身高）**
   - 所有造型基准图（`ref_look_*.png`）必须生成**平地并排自然站立、头到脚（含鞋/脚）完整入镜且脚底留有余白**的全身图，并写明肩高/头顶对齐标尺。
3. **普适 `Look` 切换 + 页级轻量覆盖（`outfit_overrides_en`）**
   - **大幅换装建新 `Look`**：跨季节（夏装→冬装羽绒服）、奇幻变装（便装→宇航服）在 `looks` 中建第 2、第 3 套造型（第 2 套起以第 1 套站姿图作 `image1` 参考链式锁脸锁身高）。
   - **单页局部微调直接用 `outfit_overrides_en`**：如仅 1–2 页需要脱鞋赤脚踩水、披毛毯或戴草帽，无需新建基准图，直接在页级填 `outfit_overrides_en`。当微调中包含 `barefoot` 时，编译器**自动剥离**原 `Look` 中的鞋袜词（`sneakers / shoes / boots / sandals / socks`），彻底根治“穿运动鞋踩海浪”。

## 二、图文同源互补、防“全书排排站”与空间装修锚定

1. **「事件同源、繁简分流」（既有文学美感又 100% 图文对齐）**
   - 每页先定 10 字以内的 `event_core`（唯一瞬间事件）。
   - **英文 Prompt 做加法**：写全颜色、材质、相对位置等客观细节；**中文 `text_zh` 做减法**：锚定当前动作，删掉“红白格子/奶油白”等生图参数词，融入声音、对话、触感与全书 `story_thread` 串珠线；同时将中文里点出的具象物体填入 `caption_nouns_en` 接受编译器硬核验。
2. **彻底打破「全书一字排开罚站」（严禁照抄基准图队列）**
   - 由于 `ref_look` 站姿基准图是多人从左到右并排站立，若不显式打破队形，生图模型会把全书每一页都画成完全相同的“从左到右排排站”！
   - 编排多人页面时，相邻页**必须主动变化站位与景别**：交替采用**围成半圆互动、前后景错落（一人前景半蹲/奔跑、家人在中景呼应）、围坐茶几/野餐布、侧身并肩行走**等自然构图，并改变角色的左右相对次序；编译器亦会自动注入防排排站约束。
3. **同一房间 / 同一场地防“中途换装修”（`location_group` 锚点复用）**
   - 当同一个家或同一片公园跨时段出现（如 `home_day` 白天客厅 → `home_night` 夜晚客厅，或 `park_day` → `park_sunset`），必须为它们填写相同的 `"location_group"`（如 `"living_room"` 或 `"park_lawn"`），并**原样复制同一套窗框材质颜色、窗帘款式、沙发颜色或标志性树林描述**，仅修改窗外天色与室内灯光，严禁白天白纱窗、晚上突变深棕木格窗或公园树林突变荒原。

## 三、室内外物理常识、道具闭合、单向时间线与防切脚留白

1. **室内外物理常识与因果顺序硬红线（杜绝“在客厅放飞风筝 / 穿运动鞋上床”）**
   - **户外道具室内收纳态**：每个 `scenes` 标注 `"environment": "indoor"` 或 `"outdoor"`。凡风筝、自行车、雨伞、帐篷、桨板等户外激活类道具标注 `"outdoor_active_only": true`——在室内场景中，`prop_states_en` **必须写明平放在桌面/地板、折叠抱在怀中或挂在墙面**，严禁在室内写升空飞翔（编译器自动拦截 `flying / airborne / aloft` 等违和词并抑制孤立风筝参考图诱发升空先验）；动作顺序须符合因果（先在家平放系线 → 出门到草地 → 迎风起飞）。
   - **居家起居与灯光一致**：回家上床/地毯/睡前道晚安页，必须在 `outfit_overrides_en` 中写明脱去外鞋（`barefoot` 或 `indoor slippers, NO outdoor sneakers`），且睡前告别应朝向身旁家人而非冲镜头挥手；若文案写“灯暗啦/关灯”，场景光线必须同步写微弱夜灯或窗外月光（`bedside lamp turned off, dim moonlight`），不可灯火通明。
2. **道具必填挂载状态、随身小件防巨型贴图 & 倒水/牵线物理闭合**
   - 凡启用 `present_props` **必填** `prop_states_en`；随身小件设 `"is_small_accessory": true`（仅 `focus_props` 特写页传 1:1 道具参考图）。
   - **倒液体/牵绳连线防穿帮**：涉及倒水/倒果汁时，只让 **1 名角色**双手稳持水壶对准 **1 只明确的杯口**倾倒（其余角色端杯等候，禁止多人手部同时指向地面杯子以免手指凭空喷果汁），且地面餐具须垫野餐垫或托盘；放风筝/牵气球须写明 `holding a kite spool with continuous taut string connected all the way to {kite}` 防半空断线。
3. **单向时间线硬约束（防「晚霞 → 白天 → 落日」倒流）**
   - 每个 `scenes` 必填 `time_of_day`（`morning < day < sunset < night`）并内嵌对应光线词；同一天内时间倒退会被编译器直接报错拦截（跨天/跨季在新一天起始页设 `"day": 2`）。
4. **画幅精准匹配 + 底部 15% 前景地面保护（防切脚尖 + 中文避头点排版）**
   - 方形书封面用 `1:1`、正文插画框用 `4:3` 横画幅生成，镜头略微后退确保鞋子与前景杯具上方完整落于画面底部 15% 留白区之上；`build_pdf.py` 采用底部优先对齐（`vertical_focus=0.80`）与中文标点避头禁则 + 末行孤字平衡，彻底杜绝切脚尖与单独一个句号掉行。
